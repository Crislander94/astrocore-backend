### 3. ✅ Sistema de Autenticación Passwordless (11:15 - 14:30)
**Estado:** COMPLETADO
**Descripción:** Implementación completa de autenticación sin contraseña, alineada con frontend

#### 3.1 Modelos de Dominio
**Archivos:**
- `src/domain/entities/User.ts` - Entidad usuario sin password
- `src/domain/entities/VerificationCode.ts` - Códigos de 6 dígitos
- `src/domain/repositories/UserRepository.ts` - Interface repositorio
- `src/domain/repositories/VerificationCodeRepository.ts` - Interface códigos

**Características:**
- Sistema passwordless (solo email)
- Códigos de verificación de 6 dígitos
- Expiración configurable (10-15 minutos)
- Tipos: LOGIN, REGISTER, PASSWORD_RESET

#### 3.2 Casos de Uso
**Archivos:**
- `src/application/use-cases/auth/LoginUseCase.ts`
- `src/application/use-cases/auth/RegisterUseCase.ts`
- `src/application/use-cases/auth/VerifyCodeUseCase.ts`

**Flujo implementado:**
1. **Registro:** email + firstName + lastName → código por email
2. **Login:** solo email → código por email
3. **Verificación:** email + código → JWT tokens

#### 3.3 Servicios de Infraestructura
**Archivos:**
- `src/infrastructure/database/repositories/PrismaUserRepository.ts`
- `src/infrastructure/database/repositories/PrismaVerificationCodeRepository.ts`
- `src/infrastructure/external/JwtServiceImpl.ts`
- `src/infrastructure/external/EmailServiceImpl.ts`

**Funcionalidades:**
- Persistencia con Prisma
- Generación JWT (access + refresh tokens)
- Envío de emails con templates HTML
- Gestión de códigos con expiración

#### 3.4 API Endpoints
**Rutas implementadas:**
```
POST /api/auth/register        - Registro de usuario
POST /api/auth/login          - Inicio de sesión
POST /api/auth/verify-login   - Verificar código login
POST /api/auth/verify-register - Verificar código registro
POST /api/auth/refresh        - Renovar tokens
POST /api/auth/logout         - Cerrar sesión
GET  /api/users/profile       - Obtener perfil
PUT  /api/users/profile       - Actualizar perfil
DELETE /api/users/profile     - Desactivar cuenta
```

#### 3.5 Middleware de Seguridad
**Archivo:** `src/infrastructure/web/middlewares/authMiddleware.ts`

**Funcionalidades:**
- `authenticate` - Verificar JWT token
- `requireEmailVerified` - Requiere email verificado
- `requireAdmin` - Solo administradores
- `requireSuperAdmin` - Solo super administradores
- `optionalAuth` - Autenticación opcional
