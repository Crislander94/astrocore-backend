## 🔧 Comandos de Prueba

### Compilar y ejecutar
```bash
npm run build
npm run dev
```

### Probar flujo completo (requiere servidor corriendo y tokens)
```bash
# 1. Agregar productos al carrito
curl -X POST http://localhost:3000/api/cart \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <user_token>" \
  -d '{"productId": 1, "quantity": 2, "iva": true}'

# 2. Ver carrito
curl -H "Authorization: Bearer <user_token>" http://localhost:3000/api/cart

# 3. Crear orden desde carrito
curl -X POST http://localhost:3000/api/orders \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <user_token>" \
  -d '{"shippingAddressId": "addr_123", "notes": "Entregar en horario laboral"}'

# 4. Ver órdenes del usuario
curl -H "Authorization: Bearer <user_token>" http://localhost:3000/api/orders?page=1&limit=10

# 5. Ver orden específica
curl -H "Authorization: Bearer <user_token>" http://localhost:3000/api/orders/order_123

# 6. Actualizar estado (solo admin)
curl -X PUT http://localhost:3000/api/orders/order_123/status \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <admin_token>" \
  -d '{"status": "CONFIRMED"}'
```
